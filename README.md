# Funniest Autocorrect Fail

One line (≤199 characters): a message as sent, with an autocorrect fail in it.

> Grandma, I can't wait to visit for my yeast infection this weekend. I mean Easter. EASTER. Please delete this.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
